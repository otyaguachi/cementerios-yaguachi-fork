# Valores de cementerios · Versión didáctica

Misma calculadora de valores del GAD Municipal de San Jacinto de Yaguachi, con una página más visual: secciones con emojis, insignias de unidad ($, %, m, m², cantidad), indicadores de totales y colores tecnológicos.

- El PDF que se exporta es idéntico al de la versión formal: una hoja por apartado, listo para presentar.
- Funciona sin servidor: `index.html` y la carpeta `lib/`.

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, carpeta `/ (root)` → Save.
